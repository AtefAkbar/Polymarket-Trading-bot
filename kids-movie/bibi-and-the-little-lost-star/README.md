# Bibi and the Little Lost Star — an animated bedtime story, built from code

An 11m14s original 2D animated children's film (1920×1080, 24 fps), generated end to end by scripts:

| Stage | File | What it does |
|---|---|---|
| Story + choreography | `story.py` | Script, per-beat camera/character keyframes (timed to spoken lines), effects, sound cues → `build/timeline.json` + `build/plan.json` |
| Voices | `voice.py`, `tts.py` | Seven character voices with Kokoro TTS (Apache-2.0) via `sherpa-onnx`; mouth-movement envelopes for lip-sync |
| Score + sound | `music.py`, `sfxlib.py` | Original music (lullaby theme, two songs, mood cues) and all sound effects/ambience synthesised with numpy/scipy |
| Mix | `mix.py`, `captions.py` | Voices + score + SFX + ambience, voice-activity ducking → `audio.wav`; two-line `captions.srt` |
| Animation engine | `engine/*.js` | Canvas-2D renderer: characters, 11 scenes, parallax camera, lighting, lyrics, title cards |
| Render | `render.js`, `renderall.js` | Headless Chromium (Playwright) → ffmpeg, in parallel segments |
| Finish | `finish.sh`, `thumb.js` | Loudness-normalised final MP4 (-16 LUFS) and a 1280×720 thumbnail |

## Rebuild

```bash
pip install sherpa-onnx numpy scipy pillow
npm install                      # @fontsource/fredoka (rounded font); needs `playwright` + Chromium available
# Kokoro voice model (Apache-2.0) -> models/kokoro-en-v0_19/
curl -L https://github.com/k2-fsa/sherpa-onnx/releases/download/tts-models/kokoro-en-v0_19.tar.bz2 | tar xj -C models

python3 story.py                 # voices + timeline   (first run ~4 min of TTS; cached afterwards)
python3 mix.py                   # audio.wav (+ captions.srt via captions.py)
node renderall.js 4 960          # build/video_silent.mp4  (~10 min on 4 cores)
./finish.sh                      # build/bibi_and_the_little_lost_star.mp4
node thumb.js build/thumbnail.jpg
python3 youtube_notes.py        # build/youtube_notes.md: title ideas, description with exact chapters, tags
```

## Make a new episode

Edit `story.py`: every `beat(...)` is one scene — `lines` (who says what), `cam` (camera keyframes), `actors`
(position/emotion/animation keyframes) and `fx`. Times can be seconds, or tied to a spoken line:
`"L3"` = start of line 3, `"L3e-0.4"` = 0.4s before line 3 ends, `"e"` = end of beat. Scenes live in
`engine/scenes_*.js`; characters (Bibi, Mama, Tuck, Odo, Luma) in `engine/chars.js`.
Voices are assigned in `voice.py` (`VOICES`), music cues in `music.py` (`MUSIC` list at the bottom of `story.py`).

## Notes
- The shell scripts use this container's Playwright/Chromium paths (`/opt/node22/lib/node_modules/playwright`, `/opt/pw-browsers/chromium`) — adjust at the top of `render.js`, `thumb.js`, `scan.js`, `shot*.js` if yours differ.
- `node scan.js` lists moments where a character is off-screen — handy after changing the choreography.
- The songs are instrumental with karaoke-style lyrics on screen (the TTS model can't sing).
- Narration pacing lives in `voice.py` (`VOICES`: speed per character); slower = longer film.
